DevFeed API

Adressierung und Zugriff.

Die Website und die API liegen unter derselben Domain. Caddy terminiert TLS und leitet ausschließlich den API Teil an den lokalen DevFeed Dienst weiter.

Öffentliche API

Für Browser, Bots und Tools ohne Zugangsdaten. Sie enthält nur die bereinigte Lesesicht ohne Discord Rohpayload.

Basis https://deutsche-deadlock-community.de/devfeed/api/public/v1 Liste GET /messages?limit=30 Eintrag GET /messages/<message_id> Kartenbild GET /messages/<message_id>/card.svg

Authentifizierte API

Für Server Integrationen mit höherem Limit und Cursor. Der Schlüssel gehört ausschließlich in einen Server Prozess oder Secret Store.

Basis https://deutsche-deadlock-community.de/devfeed/api/v1 Header Authorization: Bearer <API Schlüssel> Alternative X-API-Key: <API Schlüssel> Cursor GET /messages?after=<message_id>&limit=100

Datenmodell

Ein Primäreintrag enthält die Entwickler Nachricht. context enthält nur bereinigte Nachrichten, die als Antwortkontext zu diesem Eintrag gespeichert wurden.

{ "message_id": "…", "author_name": "Yoshi", "content": "…", "sent_at": "…", "caught_at": "…", "jump_url": "https://discord.com/channels/…", "attachment_count": 0, "embed_count": 0, "context": [] }

Sicherheitsgrenze

Der öffentliche Host erhält keinen Zugriff auf Deadlock Brain oder die Deadlock Bots Datenbank. Der DevFeed läuft in der eigenen Datenbank deadlock_devfeed. Der Ingest besitzt nur INSERT Rechte auf die private Tabelle. Der API Dienst besitzt nur SELECT Rechte auf eine bereinigte View. Das vollständige Discord Rohpayload ist für den API Benutzer nicht lesbar.
