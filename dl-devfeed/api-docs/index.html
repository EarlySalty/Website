DevFeed API

Leseschnittstelle für Integrationen.

Die API liefert ausschließlich bereinigte Feed-Daten. Das vollständige Discord-Rohpayload und Datenbankzugänge werden nicht veröffentlicht.

Öffentlicher Browser-Pfad

Ohne Schlüssel

Für die Website und einfache öffentliche Leser. Maximal 50 Einträge pro Abruf.

Liste, neueste zuerst GET /devfeed/api/public/v1/devfeed/messages?limit=30 Eintrag GET /devfeed/api/public/v1/devfeed/messages/<message_id> Gerenderte PNG-Karte GET /devfeed/api/public/v1/devfeed/messages/<message_id>/card.png

Authentifizierte API

Für Server-Clients

Der API-Key wird als Bearer-Token oder über X-API-Key gesendet. Er gehört niemals in Browser-Code, öffentliche Repositories oder URLs.

Basis https://deutsche-deadlock-community.de/devfeed/api/v1/devfeed Header Authorization: Bearer <API-Key> Liste GET /devfeed/api/v1/devfeed/messages?limit=50&after=<message_id> Eintrag GET /devfeed/api/v1/devfeed/messages/<message_id> PNG-Karte GET /devfeed/api/v1/devfeed/messages/<message_id>/card.png

Antwortschema

Sanitisiert

Ein Feed-Eintrag enthält Autor, Discord-IDs, Zeitstempel, Text, Sprunglink, Attachment-/Embed-Zähler und gegebenenfalls die aufgelöste Antwortkette.

Nicht enthalten raw · Tokens · Datenbankzugang · interne Cursor Quelle https://discord.com/channels/<guild>/<channel>/<message>
